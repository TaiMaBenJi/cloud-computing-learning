学习约定（请遵守，效果翻倍）

  1. 每天 2 小时：1 小时跟着做，1 小时自己练。
  2. 第 1-3 章禁止跳读（一切的地基）；4 章之后可按需选学。
  3. 每个"动手环节"必须真的动手：不执行 = 没学。
  4. 看到报错先别慌：翻译报错 → 对照每节的"出错了怎么办"。
  5. 学完一章做自检：自检清单 80% 以上勾选才继续。
  6. 建自己的"命令笔记本"：记录每次遇到的命令和坑——半年后这是你最宝贵的财富。
