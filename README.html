🚀 三步开始

  1. 装环境 —— 跑 setup/ 里对应你系统的那条命令，然后 bash setup/check-env.sh 体检
  2. 打地基 —— 打开 Linux 21 天计划，每天 60–90 分钟，一张卡照做
  3. 开练 —— 打开 30 天作战板 填上比赛日期，按表推进
  4. 每周末打一卷 —— 打开 模拟中心，计时、评分、复盘
不想装环境？直接看 教程 和 真题题库，纸上也能先入门。
